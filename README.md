# BangCut (방컷)

쉽고 가벼운 영상 편집기입니다. 레이어 타임라인, 전환·특수 효과, 텍스트·자막, 키프레임까지 내 컴퓨터에서 바로 편집합니다.

**100% 무료 · 가정용·상업용 모두 사용 가능 · 워터마크 없음 · 광고 없음 · 정보 수집 없음 · 인터넷 연결 없음**

## 다운로드

오른쪽 **Releases**에서 최신 버전을 받으세요. 안내 페이지: https://banx.kr/bt/bcut/

| 운영체제 | 파일 |
|---|---|
| Windows 10 / 11 (64비트) | `BangCut-Setup.exe` |
| macOS (Apple 실리콘) | `BangCut.dmg` |

- 코드 서명이 없어서 Windows에서 처음 실행할 때 "Windows의 PC 보호" 창이 뜰 수 있습니다. **[추가 정보] → [실행]**을 누르세요.
- Apple 공증을 받지 않아 macOS에서 처음 실행하면 "BangCut을(를) 열 수 없음" 창이 뜹니다. **[완료]**를 누른 뒤(휴지통으로 이동하지 마세요) **시스템 설정 → 개인정보 보호 및 보안** 아래쪽의 **[그래도 열기]**를 누르고 암호를 입력하세요. 한 번만 하면 됩니다. Intel 맥은 지원하지 않습니다.

## 주요 기능

- **레이어 타임라인**: 영상·이미지·소리를 트랙에 겹쳐 놓고 옮기기·자르기·나누기, 여러 클립 고르기, 복사·붙여넣기·복제, 빈칸 없이 지우기, 소리 분리
- **미리보기에서 바로 편집**: 끌어서 위치·크기·회전, 가운데·가장자리에 붙기
- **전환 23가지**: 디졸브·닦아내기·밀어내기·확대·원형과 글리치 전환 10가지
- **특수 효과 91가지**: 글리치 26가지, 눈·비·반짝이·불꽃놀이 같은 입자, 빛, 레트로(VHS·필름), 왜곡, 움직임, 화면 분할, 색
- **렌즈 플레어 18가지**: 빛 자리와 방향을 키프레임으로 움직이고, 앞 물체에 가려지면 약해짐
- **클립 애니메이션**: 들어오기·나가기 18가지, 반복 9가지
- **레이어 효과**: 블렌드 모드 9가지, 색 보정(밝기·대비·채도·색온도·하이라이트·그림자·색조·틴트), LUT(.cube), 비네트·선명하게, 자르기·뒤집기
- **크로마키**(스포이트로 색 고르기)와 **마스크**(원·사각형·선형·띠·하트·별·직접 그리기)
- **텍스트**: 시스템 글꼴과 글꼴 파일, 외곽선·그림자·배경, 등장·퇴장 애니메이션
- **SRT 자막**: 불러오면 자막마다 텍스트 클립으로 놓여 편집할 수 있고, SRT로 저장하거나 영상에 입혀 내보냄
- **스티커·도형**: 도형 16가지와 이모지 스티커
- **키프레임**: 위치·크기·회전·불투명도와 색 보정·마스크·효과·텍스트 같은 숫자·색 값 모두
- **속도** 0.1~10배, 거꾸로 재생, 정지 화면
- **소리**: 클립 음량·페이드, 음량 키프레임, 트랙 음량·음소거, 파형, 소리 막대
- **움직이는 GIF·WebP·APNG** 반복 재생
- **MP4 내보내기**(H.264 + AAC, OS 하드웨어 인코더), 프로젝트 저장·열기(`.bcut`), 자동 저장과 복구, 실행 취소

## 지원 형식

- 영상: MP4, M4V, MOV, WEBM, MKV, AVI, WMV, FLV, TS, MTS, M2TS, MPG, MPEG, 3GP, OGV, ASF, VOB, DIVX, F4V, M2V, RM, RMVB, MXF
- 이미지: PNG, APNG, JPG, JPEG, WEBP, GIF, BMP, AVIF, SVG
- 소리: MP3, M4A, AAC, WAV, FLAC, OGG, OGA, OPUS, WMA, AIFF, AC3, AMR, MKA
- 자막·색: SRT, CUBE(LUT)
- 바로 열리지 않는 형식(AVI·WMV 등)은 미리보기용으로 바꿔서 엽니다. 내보낼 때는 원본을 읽습니다.

## 단축키 (맥은 Ctrl 대신 ⌘)

| 키 | 동작 | 키 | 동작 |
|---|---|---|---|
| `Space` | 재생 / 일시정지 | `←` `→` | 한 프레임 (`Shift` 1초) |
| `S` | 재생 헤드에서 나누기 | `Delete` | 고른 클립 지우기 (`Shift` 빈칸 없이) |
| `Ctrl`+`Z` | 실행 취소 | `Ctrl`+`Shift`+`Z` | 다시 실행 |
| `Ctrl`+`X` `C` `V` | 잘라내기·복사·붙여넣기 | `Ctrl`+`D` | 복제 |
| `Ctrl`+`T` | 텍스트 넣기 | `Ctrl`+`Shift`+`D` | 소리 분리 |
| `Ctrl`+`I` | 미디어 가져오기 | `Ctrl`+`E` | 내보내기 |
| `Ctrl`+`S` | 저장 | `Ctrl`+`O` | 열기 |
| `=` `-` | 타임라인 확대 / 축소 | `Home` `End` | 처음 / 끝 |

## 라이선스

BangCut은 개인·가정·기업·학교 등 어디서든 무료로 사용할 수 있고, BangCut으로 만든 영상의 권리는 만든 사람에게 있습니다.
원본 그대로 무료 재배포는 가능하지만 판매나 변조 배포는 할 수 없습니다. 전문은 [LICENSE.txt](LICENSE.txt)를 보세요.
